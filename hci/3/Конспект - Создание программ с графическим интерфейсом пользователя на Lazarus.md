
Lazarus - открытая среда ПО для компилятора языка Free Pascal. Одним из важных аспектов является то, что Free Pascal не только прост в использовании, но и поддерживает множество функций, характерных для современных языков программирования. Также имеется возможность использования богатого набора библиотек и пакетов, охватывающих различные области (графика, базы данных, сетевые технологии, веб-разработка и т.д.).
Как говорилось выше, Lazarus является открытой средой ПО, поэтому он распространяется бесплатно. Скачать его можно по [ссылке](https://sourceforge.net/projects/lazarus/files/Lazarus%20Windows%2064%20bits/Lazarus%204.6/lazarus-4.6-fpc-3.2.2-win64.exe/download).
Рекомендую освободить памяти минимум 2 ГБ для его хранения.

Создание нового проекта: Проект -> Создать проект... (В основном выбирается Приложение -> ОК _или_ Простая программа -> ОК)
Сохранение проекта: Проект -> Сохранить проект как...
Открытие проекта: Проект -> Открыть проект... _или_ ==Ctrl+F11==
Запуск программы: Запуск -> Запустить... _или_ ==F9==

Создание обработчика события (пример - нажатие на кнопку)
- Дважды щёлкнуть левой кнопкой мыши по кнопке на форме
- Lazarus автоматически создаст процедуру в разделе implementation
- Написать код внутри begin...end
- ``` pascal
  procedure TForm1.Button1Click(Sender: TObject);
begin
  ShowMessage('Кнопка нажата!');
end;
  ```
  
## Кнопка (TButton):

За что отвечает: запуск действия по клику пользователя
Главное свойство: Caption (текст, который видит пользователь)
Главное событие: OnClick (код, который выполнится при нажатии)
## Поле ввода (TEdit):
За что отвечает: ввод текста или чисел с клавиатуры
Главное свойство: Text (содержимое поля)
Полезное событие: OnChange (срабатывает сразу при изменении текста)
## Надпись (TLabel):
За что отвечает: вывод статического текста, подписей или результатов
Главное свойство: Caption (отображаемый текст)
## Многострочное поле (TMemo):
За что отвечает: вывод нескольких строк, лога или длинного текста
## Как изменить текст элемента в коде:

```

## Как переименовать компонент:
1. Выделить компонент на форме
2. В Инспекторе объектов найти свойство Name
3. Ввести новое имя (например, BrrBrrPatapim вместо Button1)

## MVC
• **Model (модель)** — _данные и логика_. Хранит состояние, работает с БД, применяет правила. Не зависит от интерфейса.
• **View** — _визуальное отображение_. Рисует данные Model, фиксирует действия пользователя, передаёт их в Controller. К ним относятся файлы .lfm, .ico.
• **Controller** — _обработчик ввода_. Принимает команды пользователя, вызывает методы Model, выбирает/обновляет нужную View. К ним относятся файлы 
.pas Может реализовать любую часть MVC.
