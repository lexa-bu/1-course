# Исследуйте интерфейс своей программы методом GOMS
1. Tab - меняется поле ввода (m1 > m2 > r > Рассчитать)
	- Нажмите Tab, чтобы сменить поле ввода.

2. F2 - Кнопка "Рассчитать"
	- Нажмите F2, чтобы Рассчитать по формуле, которая указана справа. _Кнопка "Рассчитать" выполняет ту же самую роль._

3. Ctrl + S - Кнопка "Сохранить..."
	- Введите комбинацию Ctrl + S, чтобы сохранить файл в .txt формате. _В панели инструментов действие "Сохранить..." выполняет ту же самую роль._
	```
	{ Пример сохранения файла.txt }
m1=34
m2=77
r=65
result=6.674e-11 * 34,00 * 77,00 / (65,00 * 65,00) = F = 4,1E-011 Н
	```

4. Ctrl + O - Кнопка "Открыть..."
	- Введите комбинацию Ctrl + O, чтобы открыть файл в .txt формате. _В панели инструментов действие "Открыть..." выполняет ту же самую роль._

5. Del - Кнопка "Очистить"
	- Нажмите Del, чтобы очистить данные, включая введенные значения, результат и историю. __Кнопка "Очистить" выполняет ту же самую роль._

6. Ctrl + Q или Esc - Выход из программы
	- Введите комбинацию Ctrl + Q или нажмите Esc, чтобы закрыть программу.

7. F1 - "Об авторе"
	- Нажмите F1, чтобы узнать поподробнее об авторе.
