# Отчёт о простой компиляции в консоли.
# Simple console compilation report.

## VS Code
VS Code использует системный терминал.
![[Pasted image 20260515224240.png]]
Приведем на примере простейшей программы "Привет, мир!".
Мы пишем gcc _название_файла_.c  -o _название_компилируемого_файла_.
Если происходит ошибка компилятор нам об этом скажет:
```
название_файла: In function 'название_функции':
название_файла:8:5: error: описание ошибки
    n |     строка, где ошибка;
      | 
```
Если ошибок нет - компилятор просто соберет исполняемый файл.
На примере скриншота:
В нашем файле _test.с_ прописан код:
```c
#include <stdio.h>
#include <locale.h>
int main()
{
    setlocale(LC_ALL, "");
    printf("Привет, мир!");
    return 0;
}
```
Прописываем: `gcc test.c  -o program`.
И у нас появляется исполняемый файл `program.exe`
Запускаем его: `./program` (идентично и в PowerShell)
Выводится ==Привет, мир!==.

## IntelliJ IDEA
В IDEA терминал тоже есть, но классическая компиляция одной кнопкой делается через интерфейс.
![[Pasted image 20260515225605.png]]
В верхней части справа есть Запустить (Run). Нажимаем ее или выполняем это действие сочетанием клавиш **Shift+F10**.

# Отчёт о компиляции нескольких файлов.
# Multiple file compilation report.
## VS Code
`gcc название_файла1.c название_файла2.c -o program`
## IntelliJ IDEA
В верхней части справа есть "молочек" Build. Нажимаем ее или выполняем это действие сочетанием клавиш **Ctrl+F9**. Затем запускаем Run.
